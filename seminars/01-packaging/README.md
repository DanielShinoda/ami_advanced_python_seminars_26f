# Семинар 1 — Packaging

По лекции 1 «Packaging и tooling». Лекция даёт карту, семинар — руки:
собираем пакет, лезем внутрь колеса, публикуем на TestPyPI.

## Что здесь

| Файл | Что это |
|---|---|
| [`seminar.ipynb`](seminar.ipynb) | теория семинара, 6 разделов, ~50 минут |
| [`extra.ipynb`](extra.ipynb) | то, что не влезло: читать необязательно |
| [`task/README.md`](task/README.md) | условие задачи |
| [`task/textstat_template/`](task/textstat_template/) | заготовка: код готов, в конфиге 6 TODO |
| [`task/check_publication.py`](task/check_publication.py) | автопроверка публикации |

## Как запустить

Из корня репозитория:

```bash
uv sync
make nb          # JupyterLab → seminars/01-packaging/seminar.ipynb
```

Ноутбуки хранятся **без** выводов — чтобы диффы в git были читаемыми.
Запускай ячейки сверху вниз: первая создаёт временную песочницу,
последняя её удаляет.

Первая сборка внутри ноутбука тянет backend из сети — разово, дальше
из кэша uv.

## Что нужно от студента заранее

**До семинара**, иначе двадцать минут уйдут на почту:

1. Аккаунт на [test.pypi.org](https://test.pypi.org/account/register/).
2. Подтверждённый email.
3. Включённая 2FA — без неё загрузка не работает.
4. API-токен (Account settings → API tokens), сохранённый куда-нибудь:
   показывают один раз.

## Разделы

**`seminar.ipynb`** — 6 разделов на ~50 минут:

1. Зачем вообще пакет
2. `pyproject.toml`: три секции
3. Собираем и смотрим, что получилось
4. **Две вещи, которые ломаются молча** — entry points и package data
5. Публикация на TestPyPI
6. Задача

Раздел 4 — ядро семинара: на нём стоят TODO 5 и 6 задачи, и он же даёт
главное правило — «собралось» ≠ «собралось правильно».

**`extra.ipynb`** — 10 независимых разделов для тех, кому интересно:
теги колёс, имя дистрибутива против имени импорта, src-layout, PEP 440,
чтение строки зависимости, устройство editable-установки, `RECORD` и
`WHEEL`, зачем столько backend'ов, trusted publishing, безопасность
`pip install`.
