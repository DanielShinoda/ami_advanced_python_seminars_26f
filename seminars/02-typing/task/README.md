# Задача семинара 2 — почини то, что нашёл mypy

В `gradebook.py` шесть багов. Модуль импортируется, `pytest` зелёный.

```
mypy  (обычный)  → 5 ошибок
mypy --strict    → 7 ошибок
```

Разница — шестой баг, про утечку `Any`. Обычный mypy на него молчит.

**Что сделать.** Прогнать mypy, прочитать ошибки, починить код. Не
аннотации ослабить, а код исправить.

## Работа

```bash
cd seminars/02-typing/task

uv run mypy --strict gradebook.py     # вот твой список дел
uv run pytest test_gradebook.py       # должны остаться зелёными
```

Проверка:

```bash
make check-typing        # из корня репозитория
```

## Контракт

Чинить надо так, чтобы получилось ровно это:

| Вызов | Результат |
|---|---|
| `average([])` | `0.0` |
| `average([8, 10, 6])` | `8.0` |
| `score_of(students, "Алиса")` | средний балл |
| `score_of(students, "Никого")` | `KeyError("Никого")` |
| `summary_line(Student("Алиса", "БПМИ251", [8, 10]))` | `"Алиса — 9.00"` |
| `print_auditors([Auditor(...)])` | печатает, mypy молчит |
| `publish_to_console("отчёт")` | печатает `отчёт` |
| `parse_scores({"scores": ["8", "10"]})` | `[8.0, 10.0]`, именно `float` |

Формат строки отчёта — `f"{имя} — {среднее:.2f}"`.

## Что не считается починкой

- `# type: ignore` — mypy замолчит, баг останется.
- `cast(...)` — то же самое, только длиннее.
- Заменить тип на `Any` или убрать аннотацию.
- Ослабить сигнатуру: было `-> float`, стало `-> float | None`, и все
  вызывающие теперь сами виноваты.

Верификатор это проверяет отдельными пунктами.

Одну сигнатуру поменять **надо** — ту, где тип слишком узкий. Правильная
правка делает её более общей, а не более слабой. Какую именно — скажет
mypy, он прямо пишет подсказку.

## Подсказки по багам

1. `average` на пустом списке — что она обещает вернуть и что возвращает?
2. `score_of` зовёт `find`, а `find` умеет вернуть `None`.
3. `summary_line` склеивает строку с числом.
4. `print_auditors` передаёт `list[Auditor]` туда, где ждут `list[Student]`.
   `Auditor` — наследник `Student`, а всё равно не подходит. Почему —
   в третьем разделе ноутбука, mypy тоже пишет подсказку.
5. `publish_to_console` передаёт `ConsoleStorage` туда, где нужен
   `Storage`. Сравни методы.
6. `parse_scores` обещает `list[float]`. Посмотри, что реально возвращается,
   если в JSON приехали строки.

## Сдача

Вывод `make check-typing` — все галочки зелёные.
